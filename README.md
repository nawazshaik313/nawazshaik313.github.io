# Shaik Mohammed Nawaz — Portfolio

Personal portfolio site, live at **https://nawazshaik313.github.io**

A single-page site with a liquid-glass design. It's plain HTML, CSS and JavaScript, with no build step and no dependencies.

## Features

- Frosted-glass panels with a light reflection that follows the mouse
- Light and dark themes (matches your system setting and remembers your choice)
- Project filters: AI & Vision, Full Stack, Hardware
- Search box (press `Ctrl` + `K` or `/`) for jumping to sections, projects and links
- Contact form that opens a ready-to-send email
- Copy-email button, scroll progress bar, back-to-top button
- Works on phones and respects the reduced-motion setting

## Update the site

1. Edit `index.html`.
2. To offer a resume download, add your PDF to this folder as `resume.pdf`. The Resume button appears automatically.
3. Commit and push. GitHub Pages republishes within a minute or two.

```bash
git add .
git commit -m "Update portfolio"
git push
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
